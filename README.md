# Bookoo Scale Tools

一个无依赖的单文件网页，用桌面版 Chrome / Edge 的 Web Bluetooth 连接 Bookoo
Mini / Ultra 秤，实时查看数据并发送常用控制命令。

> 非官方工具，与 Bookoo 无关联。

## 运行

Web Bluetooth 需要安全上下文（HTTPS 或 localhost），不要直接用 `file://` 打开。

```bash
python3 -m http.server 8000
```

Chrome 打开 <http://localhost:8000/>。也可以把仓库根目录直接部署到任意静态托管
或 GitHub Pages。

## 功能

- 连接、断开、重连；显示设备名称和设备 ID
- 重量、流量、秤端计时、电量、待机、蜂鸣档位、流量平滑、单位字节
- FF11 测量数据与 FF12 自动状态 / 设备信息
- 读取序列号、当前模式和附加信息（`0A / 0F / 14`）
- 模式切换：`00` 纯称重 / `01` 流速 / `02` 比例
- 控制：去皮、进入 Ready、开始/停止/重置计时、归零并开始/退出、蜂鸣、自动关机、
  流量平滑、校准、自动停止条件、粉重、关机、重置关机倒计时
- 帧校验、包速率、链路静默提示、可选原始帧日志

## 模式速记

| 模式 | 行为 |
| --- | --- |
| `00` 纯称重 | 计时/ready 命令无效，只保留称重与去皮 |
| `01` 流速 | `04/05/06` 可直接控制计时；`0x0D` 不一定出现，以 FF11 计时为准 |
| `02` 比例 | 先发 `18` 进入 ready，再发 `04/05`；无效状态下的命令会被忽略 |

`07` 在 ready 时去皮并开始，在 stopped 时退出/去皮；`05` 停止计时。

## 兼容性

- 桌面版 Chrome / Edge（Android Chrome 也可），系统蓝牙已开启
- 连接前先断开手机上的 Bookoo App；Web Bluetooth 通常只允许一个中心连接
- Mini 未完整验证，模式切换与命令以 Ultra 为准
